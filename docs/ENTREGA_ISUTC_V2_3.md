## Demonstração de 5–7 minutos
1. Mostrar o problema real e os dados nacionais do Banco Mundial na página Indicadores, incluindo estados de carregamento/erro.
2. Navegar por Início → Indicadores → Detalhe → O meu plano → Sobre; mostrar página 404 para rota desconhecida.
3. Apresentar os componentes, composables e validação do formulário Vue 3.
4. Criar prévia gratuita de um plano de Vue ou portefólio; explicar o motor de regras e descarregar PDF local.
5. Enviar pedido real e mostrar a confirmação no Gmail; explicar o segundo e-mail agendado sem manter navegador ligado.
6. Mostrar e-mail 2 de um teste anterior com ligação privada para o PDF e explicar token de acesso temporário.
7. Mostrar separação das credenciais no Cloudflare e o repositório GitHub com PRs de todos os membros.
